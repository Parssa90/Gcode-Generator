Place the following assets here before building:
- icon.png          (1024x1024 — app icon, dark background #0a0f1e with ARIA logo)
- splash.png        (2732x2732 — splash screen)
- adaptive-icon.png (1024x1024 — Android adaptive icon foreground)
- notification-icon.png (96x96 — notification icon)

Expo provides default assets if these are missing during development.
For production, generate these using: npx expo-image-utils
